# Raw data — download instructions

Place the following files in this directory. All datasets are publicly available.

## 1. MapBiomas Collection 11
- URL: https://brasil.mapbiomas.org/
- Files: `brazil_coverage-col11_YYYY.tif` (years 1985–2025)
- Place in: `data/raw/mapbiomas/`

## 2. Landsat Collection 2 Level-2 ST
- Query via USGS STAC API: https://stac.aws.nasa.gov/landsat/
- Filter: path/row 223/061 (Belém), July–November, cloud < 30%
- Place in: `data/raw/landsat/`

## 3. MODIS MOD11A2 / MYD11A2
- URL: https://modis.ornl.gov/
- Product: 8-day composites, tile h11v09
- Place in: `data/raw/modis/`

## 4. BR-DWGD v3.2.4
- URL: https://sites.google.com/view/brdwgd/
- Files: TX and TN gridded NetCDFs
- Place in: `data/raw/brdwgd/`

## 5. INMET Belém station (WMO 82191)
- URL: https://bdmep.inmet.gov.br/
- Variables: TX, TN, precipitation
- Place in: `data/raw/inmet/`

## 6. Global temperature products
- HadCRUT5: https://www.metoffice.gov.uk/hadobs/hadcrut5/
- NASA GISTEMP v4: https://data.giss.nasa.gov/gistemp/
- NOAAGlobalTemp v6: https://www.ncei.noaa.gov/products/land-based-station/noaa-global-temp
- Place in: `data/raw/global_tair/`

## 7. Auxiliary shapefiles
- IBGE municipal boundaries: https://www.ibge.gov.br/geociencias/
- Rodovias do Pará: [source]
- Grid shapefiles: generated by `01_lulc_mapbiomas.R`
